# MicPause：MacBook 全局听写 + 说话时自动暂停网易云音乐

**先确认适用范围，再安装。**

| 项目 | 本项目的范围 |
| --- | --- |
| 设备 | **只面向 MacBook（macOS）**；不提供 Windows、Linux、手机或平板安装方案。其他 Mac 机型未纳入本项目的验证范围。 |
| 语音输入场景 | **ChatGPT、Codex、WorkBuddy 的 Mac 桌面客户端**。三者用麦时可触发音乐暂停。WorkBuddy 指腾讯的 WorkBuddy。浏览器网页版、其他 AI 工具和其他录音应用不作为兼容性承诺。 |
| 全局听写范围 | **ChatGPT／Codex 桌面客户端**，并且设置中必须有“聚焦主聊天输入框”和听写“单击快捷键”两个功能。**WorkBuddy 的跨应用跳转听写未验证**：在 WorkBuddy 内使用自己的语音输入，音乐暂停仍由 MicPause 负责。 |
| 音乐播放器 | **网易云音乐 Mac 桌面客户端，中文界面**，需要有「控制 → 暂停／播放」菜单；网页版、QQ 音乐、Apple Music、Spotify 等暂不支持。 |
| 系统 | 构建目标最低为 macOS 13。不同 macOS 版本的麦克风进程归因能力不同，较旧系统可能只能检测整机用麦状态；**不承诺最低版本具有完整的按应用区分能力**。当前实际使用验证来自较新 macOS 的 MacBook；其他系统组合请先按下面的方法测试。 |
| 作用 | 开始语音输入 → 自动暂停正在播放的网易云音乐；结束语音输入、麦克风释放 → 等待约 0.6 秒后恢复。原本已暂停的音乐不会主动播放。 |
| 不需要的东西 | 不需要 OpenAI API Key、付费开发者账号、Node.js、Python 或 Homebrew。需要安装 Apple 的命令行开发工具，用来在自己的电脑上编译。 |

**装完整套工具后，你可以得到的效果：**

1. 在桌面、浏览器等其他应用按 **Command + Shift + D（⌘⇧D）**。
2. 自动回到当前 ChatGPT／Codex 主聊天，聚焦输入框并开始听写；不是新建聊天，也不是永久绑定某一条会话。
3. MicPause 检测到用麦后，暂停正在播放的网易云音乐。
4. 再按一次 **⌘⇧D** 停止听写；文字留在输入框，**由你检查后自行发送**。
5. 客户端释放麦克风后，音乐恢复。

录音和语音转文字仍由 AI 客户端完成；本项目不提供自己的语音识别服务。全局快捷键默认定位标准“应用程序”文件夹里的 ChatGPT（优先），找不到再尝试 Codex；如果两者都安装，请确认实际被打开的是你想使用的客户端。

> 本项目采用“在自己的 MacBook 上从源码构建”的安装方式。目前没有经过 Apple 公证的通用一键安装包；不要把 GitHub 的 Source code ZIP 当成已经安装好的 App。
>
> 本仓库公开后可以直接查看和下载源码，不需要 OpenAI API Key。若链接显示 404，请检查地址是否正确、网络是否能访问 GitHub。

## 你拿到这个地址后，要做什么？

完成下面五件事：**下载源码 → 安装整套工具 → 在 ChatGPT／Codex 设置两组内部快捷键 → 给两个程序分别授权 → 从其他应用做一次真实听写测试。**

如果你不熟悉终端，优先使用路线 A。没有 Agent 工具，使用路线 B。两条路线只选一条，不要重复安装。

## 路线 A：让 Agent 帮你安装（推荐新手）

打开你正在使用的 Codex、WorkBuddy 或其他能够操作本机文件、运行终端命令的 Agent。把下面这一段完整复制给它：

```text
请帮我在这台 MacBook 上安装 MicPause。
仓库：https://github.com/ersicitro/MicPause

先读取仓库 README，确认是 macOS、能访问仓库，并检查 Apple Command Line Tools。
如果缺少开发工具，请指导我在 Apple 的安装窗口中完成安装，不要替我接受许可或绕过系统安全提示。
把源码下载到一个独立目录；如果已安装过，先确认旧版本的位置，不要复制出多个后台实例。
先检查我是否已经有旧的 MicPause 或全局听写工具在运行；不要直接运行第二个相同快捷键实例。
运行 bash script/setup-all.sh，在本机编译并安装音乐暂停和全局听写整套工具。
带我把 ChatGPT／Codex 的“聚焦主聊天输入框”设为 Control+Option+Shift+F，听写的“单击快捷键”设为 Control+Option+Shift+D；外层全局热键固定为 Command+Shift+D。
分别说明 MicPause 和 ChatGPT 听写助手要开启的设备控制权限。不要把权限给到错误的同名旧副本。

授权后，指导我退出并重新打开 MicPause，然后用网易云音乐和我的 AI 客户端完成一次开始／结束语音输入测试。
不要上传我的配置、日志、录音、聊天或其他个人文件；除上面明确指定的客户端内部两组快捷键外，不要改变其他应用的快捷键。
```

Agent 可以完成下载、检查、编译和安装，**但客户端内部快捷键和系统权限需要你确认**。安装成功不等于权限已经打开，请继续看「必做：开启权限」。

## 路线 B：自己安装，不需要会写代码

### 1. 安装 Apple 命令行开发工具

按 `Command + 空格`，搜索并打开「终端」。复制下面这行，按回车：

```bash
xcode-select --install
```

如果弹出 Apple 安装窗口，按窗口提示完成安装，可能需要等待下载。如果提示已经安装，就进入下一步。**不需要下载完整的 Xcode。**

### 2. 下载这个仓库

在本页面点绿色 **Code → Download ZIP**，下载后双击解压。

默认解压目录通常叫 `MicPause-main`。建议先放在「下载」或「文稿」里一个固定位置，不要直接在压缩包内部操作。

### 3. 让终端进入源码文件夹

如果你使用默认下载位置和默认文件夹名，可以复制：

```bash
cd "$HOME/Downloads/MicPause-main"
```

如果提示“没有这个文件或目录”：在终端输入 `cd`，再输入一个空格，然后把**解压后的整个 MicPause 文件夹**从访达拖进终端，最后按回车。该文件夹里应该能看到 `README.md`、`Sources` 和 `script`。

### 4. 一条命令编译、安装并启动

```bash
bash script/setup-all.sh
```

看到“编译成功”“已安装”后，记住终端显示的应用路径。

- 音乐暂停程序默认是 **`~/Applications/MicPause.app`**；全局听写的两个程序在 **`~/Applications/MicPause Tools/`**。通常不需要管理员权限，也不用 `sudo`。
- 如果旧版本已经装在 **`/Applications/MicPause.app`**，脚本会优先更新旧位置，避免多个实例。若这个位置不可写，终端会说明如何改装到自己的目录。
- 安装后自动启动，菜单栏会出现音乐暂停程序 MicPause 的图标。**全局听写程序默认隐藏菜单栏图标，也不常驻 Dock；没有主窗口是正常的。**
- 如果编译失败，脚本会停止并显示错误。不要在失败后继续安装；把错误交给 Agent 排查。

**第一次打开出现系统提示时**：确认打开的是你刚在本机编译的 MicPause；如果 macOS 仍拦截，保留提示并让 Agent 检查，不要关闭 Gatekeeper 或系统完整性保护，也不要运行来历不明的“解除限制”命令。

## 必做：先设置 ChatGPT／Codex 内部的两个快捷键

打开你要听写的桌面客户端：

1. **设置 → 键盘快捷键**，搜索 **“聚焦主聊天输入框”**，设置成 **Control + Option + Shift + F**（⌃⌥⇧F）。
2. **设置 → 语音 → 听写 → 单击快捷键**，设置成 **Control + Option + Shift + D**（⌃⌥⇧D），即“按一次开始、再按一次结束”的那一项。
3. 如果已有 F5 等旧听写绑定，替换掉它；“语音聊天热键”和“按住听写快捷键”不是这里要配置的项目。

两组复杂组合键是**程序内部代按**，你日常只需要 **⌘⇧D**，不用 F5／F6／F7，也不用 Fn。

不要把 ChatGPT 内部单击听写设成外层同一个 ⌘⇧D，否则会与全局入口冲突。也不用到 macOS“服务”里再添加 ⌘⇧D，本仓库使用真正的全局热键程序。

如果你的版本找不到上述命令，请先确认客户端版本和功能是否可用；缺少这两个命令时不能保证本工具能全局听写，仍可只使用音乐暂停功能。

**冲突提示：⌘⇧D 会覆盖 Finder 原来的“打开桌面”以及浏览器等应用可能使用的同名快捷键。** 本版本选择它是为了单手好按、容易记住，并不代表它原本没有占用。若已有其他工具把它注册成全局热键，请先关闭冲突的那一个；不要同时运行两份本工具。

## 必做：开启权限，然后重新打开 MicPause

### MicPause 需要哪一项？

MicPause 需要权限，才能操作网易云的「暂停／播放」菜单。不同 macOS 的名称可能不同：

** → 系统设置 → 隐私与安全（或“隐私与安全性”）→ 辅助功能**

如果找不到「辅助功能」，看看是否叫 **「设备控制和数据访问」**。不要误点系统设置左侧的「无障碍」，那是另一组功能。

1. 找到 **MicPause**，打开它旁边的开关。
2. 如果列表里没有，点 `＋`／「添加」。
3. 在选文件窗口中按 `Command + Shift + G`，粘贴安装时显示的 App 路径。首次安装通常为：

   ```text
   ~/Applications/MicPause.app
   ```

4. 选中 App，点「打开」，再开启开关；需要密码或 Touch ID 时，由你自己完成。
5. 点菜单栏的 MicPause 图标，选择「退出 MicPause」。然后从刚才的安装位置双击打开它。

**第 5 步不能省略。** 目前程序在启动时读取一次授权状态，授权后要退出并重新打开才会重新检查。只关掉权限窗口不算重启。

必须授权的是 **MicPause 本身**；只给终端、自动操作或 ChatGPT 授权，不能代替它。

### 全局听写还要单独给“ChatGPT 听写助手”授权

在同一个设备控制权限页面，再添加并允许下面这个 App：

```text
~/Applications/MicPause Tools/ChatGPT 听写助手.app
```

**MicPause 与 ChatGPT 听写助手要分别允许**：前者控制音乐，后者切回聊天、聚焦并代按听写快捷键。只开启“自动操作”或“工作流程 Runner”不能代替它们。

首次按 ⌘⇧D 时，如果系统询问是否允许助手控制 ChatGPT／Codex 或 System Events（系统事件），核对请求方为你安装的“ChatGPT 听写助手”后，由你本人确认允许。已有拒绝记录时，到 **隐私与安全 → 自动化** 中检查助手对应的目标开关。

全局热键程序只注册指定的 ⌘⇧D，不记录其他键盘输入，不要求为了它开启输入监控或录屏。应用仍由 macOS 的设备控制／自动化权限约束。

### 语音输入应用还需要什么？

ChatGPT、Codex 或 WorkBuddy 本身需要正常的麦克风权限：

**系统设置 → 隐私与安全 → 麦克风 → 允许你使用的那个客户端**。

这与 MicPause 的设备控制权限是两回事。MicPause 本身只读“麦克风是否在使用”的状态，不录制声音；无需为了它额外开启相机、录屏、完全磁盘访问或通讯录权限。

### 登录后自动运行

首次启动会尝试登记登录启动项。菜单栏里可以查看或切换「开机自启」。如系统提示需要批准，到：

**系统设置 → 通用 → 登录项（新版可能叫“登录项与扩展”）**。

若没有自动加入，可在“登录时打开”中手动添加安装位置的 `MicPause.app`。全局听写安装脚本另行生成当前用户的登录启动项，文件为 `~/Library/LaunchAgents/io.micpause.global-dictation.plist`。这里实际指的是**登录 macOS 用户账号后启动**；不要再手动添加第二份同名热键程序。

## 第一次使用：花一分钟确认安装成功

1. 打开网易云音乐 **Mac 客户端**，开始播放一首歌。
2. 打开 ChatGPT、Codex 或 WorkBuddy 的桌面客户端。
3. 如果测试 ChatGPT／Codex：先切到浏览器或桌面，按 **⌘⇧D**，应回到当前聊天并开始录音。说一句话，再按 **⌘⇧D** 结束。若测试 WorkBuddy：在其客户端内使用自己的语音输入按钮。
4. 网易云应自动暂停；结束录音后，等待麦克风真正释放，再等约 0.6 秒，音乐应恢复。轮询和播放器响应还会带来少量延迟。
5. 再手动暂停音乐，重复一次录音；这次音乐应保持暂停。

音乐暂停部分不需要录音快捷键，它跟随麦克风状态工作。全局听写需要上面两组客户端内部快捷键和助手权限，缺一项都可能无效。一次语音输入结束后，如果客户端仍持续占用麦克风，音乐会继续保持暂停，直到客户端释放它。

如果只想安装音乐暂停、不要全局热键，可改用 `bash script/setup.sh`，并只完成 MicPause 权限配置。

## 日常怎么用？

平时让 MicPause 在后台运行即可。菜单栏图标中可以查看麦克风、网易云状态，临时「停用自动化」、切换登录启动，或退出程序。

全局听写隐藏了菜单栏图标；需要停止它时，打开“活动监视器”，找到 `GlobalDictationHotkey` 并退出。它与音乐暂停程序独立，退出其中一个不会自动退出另一个。

退出 MicPause 不会删除应用；下次双击 App 就能再次开启。不要为了隐藏 Dock 图标而结束其他进程；MicPause 本来就是菜单栏应用。

## 常见问题：按这个顺序查

| 现象 | 先怎么做 |
| --- | --- |
| ⌘⇧D 仍打开 Finder／浏览器书签 | 全局热键程序没有正常运行；打开 `~/Applications/MicPause Tools/ChatGPT 全局听写.app`，检查是否提示组合键被其他全局工具占用。不要只在“服务”中绑定。 |
| 能回到聊天，但不录音／文字进错框 | 检查客户端内两组组合键；确认设置的是听写“单击快捷键”，以及助手的设备控制和自动化授权。 |
| 报“听写助手不允许辅助访问” | 授权对象应为 `ChatGPT 听写助手.app`，不是“自动操作”或仅 ChatGPT。核对安装路径，重新授权后重试。 |
| 报“听写助手已不能再打开” | 新版会仅清理路径、用户和暂停状态都匹配的助手残留进程并重试。仍失败时不要连按；让 Agent 查进程和系统日志，不要直接删权限或关系统保护。 |
| 开始说话，音乐没有暂停 | 确认是网易云 Mac 中文客户端；菜单栏自动化为“启用”；给**实际安装位置的 MicPause**授权，再退出重开。 |
| 权限已开启，还是“状态未知” | 先退出重开；如果刚更新或重新编译，旧授权可能不再匹配。移除旧 MicPause 权限条目，添加实际新 App 并重新授权。 |
| 系统里找不到“辅助功能” | 搜索“设备控制和数据访问”；不要只在“无障碍”页找。 |
| 结束说话，音乐没有恢复 | 确认录音真正结束、其他程序没有继续用麦；只有被 MicPause 暂停的音乐才会恢复。 |
| 其他应用录音也暂停了音乐 | **默认不是三款 AI 应用的严格白名单。** 默认忽略微信、Zoom 等已列出的应用，但其他程序和无法归因的用麦也可能触发。需要严格限制时看下面的高级配置。 |
| 重启电脑后没有运行 | 查看 MicPause 菜单里的开机自启，以及系统“登录项”是否允许；手动加入实际 App。 |
| 出现两个图标、行为重复 | 检查是否同时保留了 `/Applications` 和 `~/Applications` 的副本。退出旧副本，仅保留并启动一个安装位置。 |
| Agent 说“装好了”，但不会暂停 | 安装、系统授权、退出重开、实际录音测试是四个环节，请确认都完成。 |
| 系统升级或网易云升级后失效 | 系统 API、权限和菜单名称都可能变化，不能保证未来版本永远兼容。先检查权限和菜单，再携带**脱敏后的**报错反馈。 |

不要直接上传整份日志：其中可能包含应用标识、设备名称或其他本机信息。截图也请先遮住账号、聊天、个人路径。

## 更新与卸载

**更新**：下载新版源码，在新文件夹运行 `bash script/setup-all.sh`。更新之前先退出旧 MicPause，并从活动监视器退出旧的 `GlobalDictationHotkey`；结束录音后再更新。尽量保持原安装位置；重编译后可能需要重新授权。自签名不等于 Apple 公证，不能承诺更新后权限永远不失效。

**卸载**：先从菜单栏关闭“开机自启”并退出 MicPause，再在源码目录运行：

```bash
bash script/uninstall.sh
bash script/uninstall-dictation.sh
```

全局听写也要先在活动监视器中退出 `GlobalDictationHotkey`。如系统“登录项”中仍有 MicPause，手动移除。脚本保留本地配置和日志，避免把你的设置一起删除。只想临时停用，用菜单栏开关即可。

## 高级配置：只让指定应用触发（可跳过）

配置保存在自己电脑的：

```text
~/Library/Application Support/MicPause/config.json
```

第一次正常启动时会生成。**先退出 MicPause**，再修改现有 JSON，保存后重新打开。JSON 不能写注释；不熟悉时建议让 Agent 修改，不要直接覆盖整份配置。

- `enabled`：总开关。
- `pauseDelaySeconds`：持续用麦多久才暂停，默认 `0.15` 秒。
- `resumeDelaySeconds`：麦克风释放后等待多久恢复，默认 `0.6` 秒。
- `excludedBundleIDs`：忽略的应用；请保留网易云 `com.netease.163music`，避免“听歌识曲”触发自暂停。默认还排除了微信、Zoom、Teams、语音备忘录、FaceTime 等。
- `allowedBundleIDs`：为空表示不是严格白名单；填入后仅允许匹配的应用进程。
- `treatUnattributedDeviceAsActive`：默认 `true`，无法辨认应用时也按用麦处理。**需要严格白名单时，同时设为 `false`**；代价是某些系统或客户端的语音输入可能不再被识别。
- `writeLogFile`：是否写本地诊断日志，默认 `true`。

当前常见应用标识示例：ChatGPT／Codex 桌面客户端可能使用 `com.openai.codex`，WorkBuddy 为 `com.tencent.workbuddy.mac`。应用版本、独立 ChatGPT 客户端和辅助进程可能使用其他标识，**不要只凭产品名硬填**。让 Agent 先识别你电脑上实际的用麦进程，再配置前缀匹配。

程序不会读取或上传你的 ChatGPT／Codex／WorkBuddy 配置。上面两组客户端快捷键需要安装时由你或你明确授权的 Agent 设置，安装脚本不会自动改写它们。

## 最后再看：它怎样工作？

### 全局听写

`ChatGPT 全局听写.app` 用系统 `RegisterEventHotKey` 注册 ⌘⇧D；收到该组合键时，通过系统启动旁边的 `ChatGPT 听写助手.app`。助手将客户端置于前台，发送内部的聚焦快捷键与单击听写快捷键。不会按回车发送消息。

全局入口带 0.5 秒防连按、启动互斥和失败超时释放；遇到已确认暂停卡住的助手进程时，仅处理当前用户且可执行路径完全匹配的进程，并在二次核对后清理。只在确认清理到了这种残留时重试一次，避免盲目重复启动把录音切换两遍。这些保护降低已知问题概率，不能保证未来系统更新永远无故障。

### 检测用麦

每 250ms 通过 CoreAudio 查询音频进程是否正在输入，并读取进程的 Bundle ID；无法归因时，按配置决定是否使用整机输入设备的运行状态作为兜底。读取运行状态不等于录音，不读取语音内容，也不做转写。

默认检测不严格限制为三款 AI 工具，具体边界已在开头和排查表中说明。其他应用持续用麦、辅助进程归因不完整、系统版本差异，都可能影响暂停／恢复时机。

### 控制网易云

通过 macOS 的设备控制／辅助功能接口找到网易云原生菜单：

```text
控制 → 暂停 / 播放
```

菜单显示“暂停”时视为正在播放，显示“播放”时视为已暂停。MicPause 只在原本播放时发送暂停，并记录这次暂停是否由自己发起；麦克风释放后，仅在仍是暂停状态时发送恢复。播放状态或菜单未知时，不盲目发送切换命令。

网易云语言或菜单结构变化可能让控制失败。未采用内容区点击坐标，也不把音频输出通道仍开启当作“正在播放”的依据。

### 文件与隐私

仓库包含 Swift 源码、通用图标和构建／安装脚本；应用在本机编译，编译产物不提交进 Git。源码中不包含项目维护者的本机路径、配置、日志、账号、证书私钥或 API Key。

运行配置：`~/Library/Application Support/MicPause/config.json`。本地日志：`~/Library/Logs/micpause.log`。全局程序仅将注册状态写入 `~/Library/Application Support/MicPause/global-hotkey-status.txt`，不记录按键内容。程序不包含向服务器上传这些内容的实现。下载源码和安装 Apple 开发工具时需要网络；运行时的语音处理、账号和数据政策由你使用的 AI 客户端负责。

诊断命令供有经验的用户或 Agent 使用：

```bash
bash script/build.sh
./build/micprobe state        # 只查看用麦状态
./build/micprobe watch        # 观察变化，Control+C 退出
./build/micprobe axtrusted    # 检查当前诊断进程的设备控制授权
./build/micprobe controlstate # 读取网易云菜单状态
```

诊断工具作为独立可执行文件运行时，权限身份可能与 MicPause App 不同；“诊断工具未授权”不能单独证明 App 未授权。`trymenu`、`mediakey` 等命令会改变播放状态，不应在没有说明的情况下替用户运行。
