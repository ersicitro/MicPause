# 1.1.0

- README 按新手使用顺序重写：适用范围、Agent 安装提示、手动安装、系统权限、首次测试、故障排查，然后介绍原理。
- 明确 MacBook、ChatGPT／Codex／WorkBuddy 桌面客户端、网易云 Mac 中文客户端的目标范围；说明默认检测不是严格三应用白名单。
- 新增 setup.sh 与 package.sh；首次默认安装到用户的 Applications 目录，更新时优先保留既有安装位置。
- 构建失败不再被吞掉；本地签名、安装验证和 --no-start 便于核对结果。
- 更新权限提示，覆盖“辅助功能”和“设备控制和数据访问”两种名称。
- 不分发个人配置、诊断日志、本机路径、编译缓存或签名私钥。

语音识别仍由对应客户端完成；本次将此前独立运行的全局听写工具一起开源，新增整套安装入口及客户端内部快捷键、助手权限说明。本次没有改变已安装应用或系统授权。

- 全局听写固定为 Command+Shift+D，隐藏菜单栏与 Dock 图标；包含已部署版本的暂停进程自动恢复、防连按与启动互斥保护。
- 将原先个人目录中的工具推广为相对安装路径；运行状态和登录项在用户本机生成。
